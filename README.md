# Игра «Угадай число»

Консольная игра на Go: угадайте загаданное число за ограниченное количество попыток.

## Запуск

Для запуска требуется Go версии 1.24.5 или новее.

1. Откройте терминал в папке проекта.
2. Запустите игру:

   ```powershell
   go run .
   ```

Также можно собрать исполняемый файл командой `go build .`, а затем запустить его из терминала.

## Как играть

При запуске выберите режим, введя его название:

| Режим | Диапазон | Попытки |
|---|---:|---:|
| `easy` | 1–50 | 15 |
| `medium` | 1–100 | 10 |
| `hard` | 1–200 | 5 |

Вводите целое число из указанного диапазона. Неверный ввод или число вне диапазона не расходуют попытку. После каждого неверного предположения игра сообщает, больше или меньше загаданное число, а также насколько вы близки:

- **Горячо** — разница не больше 5.
- **Тепло** — разница от 6 до 15.
- **Холодно** — разница больше 15.

Когда раунд закончится, выберите действие: сыграть еще раз, посмотреть статистику или выйти. Повторный раунд запускается в том же режиме.

## Статистика

Результаты игр сохраняются в `results.json` в текущей рабочей папке. В статистике отображаются режим, результат, количество попыток, время начала и длительность игры. Не удаляйте этот файл, если хотите сохранить историю игр.
